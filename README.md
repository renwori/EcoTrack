# 🌿 ЭкоТрек

Сайт: `index.html` + `config.js` (адрес сервера). Сервер — Google Apps Script на Google Таблице: `Code.gs` и дополнение `Badges.gs`.

## Учителя, бейджи и аватарки — как включить

1. Откройте Google Таблицу → **Расширения → Apps Script**.
2. Рядом с `Code.gs` нажмите **＋ → Скрипт**, назовите файл `Badges`, вставьте содержимое `Badges.gs`.
   Файл `Badges` должен стоять в списке **ниже** `Code.gs`. Сам `Code.gs` менять не нужно.
3. В списке функций выберите `setupBadges` и нажмите **Выполнить** (создадутся листы Avatars, Classes, Members, Badges).
4. **Настройки проекта (⚙️) → Свойства скрипта → Добавить свойство**:
   `TEACHER_CODE` = ваш секретный код. Его вы даёте учителям для регистрации. Без него регистрация учителей выключена.
5. **Развернуть → Управление развёртываниями → ✏️ → Версия: «Новая версия» → Развернуть.**
   Так адрес не меняется, и `config.js` трогать не нужно.

## Как это работает

- **Учитель** регистрируется с кодом учителя (переключатель «Я учитель») или вводит код в Настройках.
  У учителя появляется вкладка **«Класс»** с кодом класса из 6 символов.
- **Ученик** вводит код класса в профиле («Мои учителя» → «Вступить»).
- Учитель выдаёт ученику **бейдж**: значок, цвет, название и описание пишет сам. Отозвать бейдж может только тот, кто его выдал.
  Новый бейдж ученик увидит с анимацией при следующем открытии профиля.
- **Аватарка**: нажмите на фото или 📷 в профиле, обрежьте и сохраните. Фото сжимается до 192×192 и хранится в таблице.

## Как откатиться к исходной версии

Исходное состояние — коммит `29749f8` (ветка `main` до этих изменений).

```bash
git checkout main -- index.html Code.gs config.js
```

В Apps Script достаточно удалить файл `Badges` и снова развернуть новую версию. Перед обновлением сделайте копию таблицы (**Файл → Создать копию**).
