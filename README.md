# 🌿 ЭкоТрек

Сайт: `index.html` + `config.js` (адрес сервера). Сервер - Google Apps Script на Google Таблице: `Code.gs` и дополнение `Badges.gs`.

## Как установить или обновить `Badges.gs`

1. Откройте Google Таблицу → **Расширения → Apps Script**.
2. Откройте файл `Badges` (если его нет: **＋ → Скрипт**, имя `Badges`), удалите всё старое содержимое и вставьте `Badges.gs` целиком.
   Файл `Badges` должен стоять в списке **ниже** `Code.gs`. Сам `Code.gs` менять не нужно.
3. Сохраните (**Ctrl+S**), выберите функцию `setupBadges` и нажмите **Выполнить** (создаст недостающие листы).
4. **Настройки проекта (⚙️) → Свойства скрипта**: должно быть свойство `TEACHER_CODE` = ваш секретный код для учителей.
5. **Развернуть → Управление развёртываниями → ✏️ → Версия: «Новая версия» → Развернуть.**
   Адрес не меняется, `config.js` трогать не нужно.

## Что умеет

- **Учитель** регистрируется с кодом учителя (переключатель «Я учитель») или вводит код в Настройках.
  У учителя есть вкладка **«Класс»** с кодом класса из 6 символов.
- **Ученик** вводит код класса в профиле («Мои учителя» → «Вступить»).
- **Бейджи**: учитель выдаёт их ученикам своего класса - значок, цвет, название и описание пишет сам.
- **Разработчик** (@renwori): фиолетовый тег «Разработчик», может выдавать бейджи любому пользователю
  (вкладка «Класс» → «Выдать бейдж любому пользователю»). Роль закреплена за аккаунтом, а не за юзернеймом.
- **Чаты** (вкладка «Чаты»):
  - личный чат появляется, когда двое стали друзьями;
  - чат класса - для учителя и учеников, которые вступили по коду. Учитель может удалять сообщения в чате класса.
  - Только текстовые сообщения (до 1000 символов). Удалить своё сообщение - правый клик (на телефоне - долгое нажатие).
  - Новые сообщения подгружаются раз в 3 секунды.
- **Мини-игры**: «Сортировка мусора», «Эко-викторина», «Миф или правда». XP - за первую удачную игру каждого вида в день.
- **Серия дней 🔥**: каждый день, когда сыграна хотя бы одна мини-игра, продлевает серию. Пропуск дня сбрасывает её до нуля.
- **Задания дня**: 3 задания из 14 каждый день, за каждое - XP. Это самоотчёт.
- **Эко-сад 🌳**: у каждого в профиле растёт дерево - от семечка до могучего дерева по мере опыта;
  при серии 7+ дней оно цветёт, 30+ - даёт плоды. У класса есть общий «лес».
- **Польза для природы**: выполненные задания дня складываются в личный и классный счётчик -
  сколько примерно воды, пластика, макулатуры, CO₂ и электричества удалось сберечь.
- **Эко-карта 🗺️** (вкладка «Игры»): пункты приёма вторсырья и батареек рядом с пользователем,
  фильтры по видам. Данные OpenStreetMap, карта Leaflet.
- **Профили**: нажмите на аватарку или имя - откроется профиль человека с его бейджами, садом и лентой достижений
  (новые бейджи, уровни, серии дней, рост сада). Видно всем пользователям.
- **Реакции в чатах**: нажмите на сообщение и выберите реакцию; там же - удаление своего сообщения.
- **Оформление профиля** (кнопка 🎨 в профиле): обложка и узор, рамка аватарки (часть открывается за уровень,
  серию дней или 3 бейджа), эмодзи рядом с именем, статус и витрина из 3 любимых бейджей.
- **Новые мини-игры**: «Как поступить?» (жизненные ситуации) и «Что дольше разлагается» (сроки по данным NOAA).
- Листы в Таблице создаются автоматически, если их нет; новые строки пишутся как текст, поэтому Таблица
  не превращает даты и «=…» в свои форматы.
- **Аватарка**: нажмите на фото или 📷 в профиле.

## Новости об экологии

Лента загружает новости из RSS раз в час. Источники - в листе **NewsSources** Таблицы:

| Колонка | Что это |
|---|---|
| name | название, которое видно в ленте |
| url | адрес RSS-ленты |
| filter | «да» - брать только новости про природу (для общих лент), «нет» - брать всё |
| status | сервер пишет сюда, работает ли источник |

Стартовые источники: N+1, Naked Science, РИА Новости (Наука), ТАСС, Минприроды России.
Чтобы проверить их сразу, выберите в Apps Script функцию `ecoCheckNews` и нажмите «Выполнить»,
затем посмотрите колонку status. Нерабочий адрес можно исправить или удалить строку, новый источник - добавить строкой.

Найденные новости сохраняются в листе **NewsArchive** и показываются в ленте 14 дней, даже когда пропали из RSS источника.
Чтобы сервер заходил в источники сам каждые 30 минут (даже когда сайт никто не открывает):
Apps Script -> **Триггеры** (значок будильника слева) -> **Добавить триггер** -> функция `ecoNewsTick`,
источник события «Время», тип «Таймер по минутам», «Каждые 30 минут» -> Сохранить.

## Почему стало быстрее

- Сайт запоминает последние данные и показывает их сразу, а свежие подгружает в фоне.
- Запросы, которые только читают данные (профиль, чаты, друзья), больше не ждут друг друга в общей очереди.
- Отметка задания и отправка сообщения появляются на экране сразу, не дожидаясь сервера.

## Как откатиться к исходной версии

Исходное состояние - ветка `backup/original` (коммит `29749f8`).

```bash
git checkout backup/original -- index.html Code.gs config.js
```

В Apps Script достаточно удалить файл `Badges` и снова развернуть новую версию. Перед обновлением сделайте копию таблицы (**Файл → Создать копию**).
