# Atoll — остров сверху экрана для Windows 10/11

Маленькая капсула в верхней части экрана. В ней время, погода и то, что сейчас играет.
Если навести на неё мышь, она раскрывается в панель с плеером, погодой, заметками и таймером.

## Что умеет (версия 0.1)

- **Яндекс Музыка прямо в острове.** Официальный сайт music.yandex.ru открывается внутри приложения.
  В аккаунт нужно войти один раз, после этого окно можно закрыть: музыка играет дальше,
  а управлять ею можно из острова (▶/⏸, следующий/предыдущий трек, перемотка, «нравится»).
  Работает с бесплатным аккаунтом и с Плюсом, VPN не нужен.
- **Интернет-радио.** Больше 30 000 станций через Radio Browser: топ России, жанры, поиск, избранное.
  Бесплатно и без ключей.
- **Свои файлы.** Выбираете папку с MP3/FLAC/M4A/OGG, есть поиск, перемешивание и повтор.
- **Край острова «танцует» под бит** любой музыки на компьютере и светится цветом обложки.
- **Погода** (Open-Meteo, бесплатно): сейчас, по часам, на 7 дней, ветер с компасом, влажность,
  давление в мм рт. ст., восход и закат.
- **Таймер** с кольцом и пресетами. Когда время выходит, остров трясётся и звенит.
- **Напоминания**: по времени или текстом «через 20 минут позвонить маме».
- **Заметки и задачи** сохраняются автоматически.
- Тёмная и светлая тема, акцентный цвет, автозапуск с Windows.

**Управление:** наведите мышь, чтобы открыть остров. Ctrl + Alt + Пробел открывает и закрывает его,
Esc сворачивает, кнопка 📌 оставляет открытым. Меню приложения — правый клик по иконке в трее.

## Как скачать готовый .exe

1. Откройте вкладку **Actions** в репозитории на GitHub и выберите запуск «Atoll — сборка для Windows».
2. Внизу страницы, в разделе **Artifacts**, скачайте `Atoll-Windows` (zip).
3. Внутри два файла:
   - `Atoll-Setup-0.1.0.exe` — обычный установщик;
   - `Atoll-Portable-0.1.0.exe` — запускается без установки.

Windows может показать «Система Windows защитила ваш компьютер», потому что у приложения нет
платной цифровой подписи. Нажмите «Подробнее», затем «Выполнить в любом случае».

## Запуск из исходников

```bash
cd atoll
npm install
npm start
```
